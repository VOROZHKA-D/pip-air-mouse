## 📖 О проекте

**PipPad** — это open-source Android-приложение, которое превращает ваш смартфон в **полноценный Bluetooth HID трекпад и Air Mouse**. Работает с **macOS**, **Windows**, **Linux** и **iPadOS** — без установки какого-либо серверного приложения на принимающей стороне.

Телефон регистрируется как **настоящее Bluetooth HID-устройство**, поэтому операционная система видит его как обычную мышь — точно так же, как вы бы подключили Logitech MX Master или Magic Mouse.

### 🎯 Зачем это нужно

- Хотите управлять Mac с дивана, не вставая за стол?
- Смотрите фильм на MacBook, а телефон под рукой?
- Презентация, где нужен пульт-указка?
- Управляете HTPC / медиацентром с телефона?
- Просто лень тянуться к мышке?

PipPad решает все эти задачи **за 10 секунд** — без Wi-Fi, без серверов, без аккаунтов, без облаков.

## ✨ Возможности

### 🖱️ Трекпад как на MacBook
- **Один палец** — перемещение курсора
- **Один тап** — левый клик
- **Двойной тап** — двойной левый клик
- **Долгое нажатие** — правый клик
- **Два пальца** — прокрутка (вертикальная и горизонтальная)
- **Свайпы** — плавное и интуитивное управление

### 🌀 Air Mouse (управление гироскопом)
- Двигайте телефоном в воздухе — курсор следует за наклоном
- Настраиваемая чувствительность (ползунок в приложении)
- «Мёртвая зона» для компенсации дрожания руки
- EMA-фильтр для устранения шума сенсора
- Идеально для презентаций и управления с дивана

### 🎮 Полный набор кнопок
- Левая кнопка мыши (ЛКМ)
- Правая кнопка мыши (ПКМ)
- Средняя кнопка (СКМ)
- Прокрутка колесом (жесты или кнопки)

### ⌨️ Клавиатура (опционально)
- Ввод текста с клавиатуры телефона прямо на Mac
- Поддержка спецклавиш: Enter, Tab, Esc, Backspace, стрелки

### 🔒 Приватность и безопасность
- **Никаких облачных серверов** — соединение идёт напрямую через Bluetooth
- **Никаких аккаунтов** — не нужно регистрироваться
- **Никакой телеметрии** — приложение не отправляет данные наружу
- **Открытый исходный код** — вы можете проверить каждый байт

## 📲 Установка

### Вариант 1: Готовый APK (самый простой)

1. Перейдите в раздел [**Releases**](https://github.com/Vorozhka/PipPad/releases) этого репозитория.
2. Скачайте последнюю версию `PipPad-vX.X.X.apk`.
3. На телефоне разрешите установку из неизвестных источников (Настройки → Безопасность → Установка неизвестных приложений).
4. Откройте APK и установите.

### Вариант 2: Из исходников (см. [ниже](#-сборка-из-исходников))

### 📋 Требования

| Параметр | Требование |
|---|---|
| **Android** | 9.0 (API 28) и выше |
| **Bluetooth** | Bluetooth 4.0+ (BLE) |
| **Гироскоп** | Обязателен для Air Mouse (опционально для трекпада) |
| **Принимающее устройство** | macOS 10.15+, Windows 10+, Linux с BlueZ, iPadOS 13+ |

> ⚠️ **iOS/iPadOS в качестве отправителя не поддерживается**: Apple не предоставляет публичного API для HID Device. Используйте Android.

## 🚀 Как пользоваться

### Шаг 1. Запустите приложение на телефоне
После установки откройте **PipPad**. Приложение запросит разрешения на Bluetooth (на Android 12+ это `BLUETOOTH_CONNECT`, `BLUETOOTH_ADVERTISE`, `BLUETOOTH_SCAN`) — **разрешите все**.

Статус в приложении сменится на **«Готово. Откройте Bluetooth на Mac»**.

### Шаг 2. Подключите к Mac
1. Откройте на Mac: **Системные настройки → Bluetooth**.
2. В списке устройств появится **«PipPad»** (или «Pip Air Mouse»).
3. Нажмите **«Подключить»**.

Через 1–2 секунды статус в приложении сменится на **«Подключено: <имя Mac>»**.

### Шаг 3. Пользуйтесь!

- **Тачпад**: водите пальцем по экрану телефона — курсор двигается.
- **Air Mouse**: нажмите кнопку «Air Mouse ON» и наклоняйте телефон.
- **Клики**: кнопки ЛКМ/ПКМ внизу экрана.
- **Прокрутка**: свайп двумя пальцами.

### Шаг 4. Отключение
Просто закройте приложение или нажмите «Отключить» в интерфейсе. Mac автоматически разорвёт соединение.

## 🛠 Сборка из исходников

### Требования
- **Android Studio Hedgehog** (2023.1.1) или новее
- **JDK 17**
- **Android SDK 34**
- **Kotlin 1.9+**

### Шаги

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Vorozhka/PipPad.git
cd PipPad

# 2. Откройте в Android Studio
# File → Open → выберите папку проекта

# 3. Дождитесь Gradle Sync

# 4. Соберите Debug APK
./gradlew assembleDebug

# 5. Установите на подключённый телефон (USB-отладка)
adb install app/build/outputs/apk/debug/app-debug.apk
```

Готовый APK появится в `app/build/outputs/apk/debug/`.

### Release-сборка (подписанная)

```bash
./gradlew assembleRelease
```

Не забудьте настроить `signingConfigs` в `app/build.gradle.kts` — см. [документацию Android](https://developer.android.com/studio/publish/app-signing).

## 🧩 Технологии

PipPad построен на современном стеке Android-разработки:

| Слой | Технология | Назначение |
|---|---|---|
| **Язык** | Kotlin 1.9+ | Основной язык |
| **UI** | Jetpack Compose + Material 3 | Декларативный интерфейс |
| **Архитектура** | MVVM + Clean Architecture | Разделение слоёв |
| **Bluetooth** | `android.bluetooth.BluetoothHidDevice` | Эмуляция HID-мыши (API 28+) |
| **Протокол** | HID over GATT (HOGP) | Передача отчётов BLE |
| **Сенсоры** | `SensorManager` + `TYPE_GYROSCOPE` | Air Mouse |
| **Асинхронность** | Kotlin Coroutines + Flow | Реактивная обработка данных |
| **Хранение настроек** | DataStore Preferences | Сохранение чувствительности, deadzone |
| **Разрешения** | ActivityResultContracts | Runtime permissions на Android 12+ |

### Как это работает под капотом

```
┌──────────────────────┐         ┌──────────────────────┐
│   Android Phone      │         │      Mac / PC        │
│                      │         │                      │
│  ┌────────────────┐  │         │  ┌────────────────┐  │
│  │  Compose UI    │  │         │  │  Bluetooth     │  │
│  │  (Touchpad,    │  │         │  │  Stack         │  │
│  │   Air Mouse)   │  │         │  │                │  │
│  └───────┬────────┘  │         │  └───────▲────────┘  │
│          │           │         │          │           │
│  ┌───────▼────────┐  │  BLE    │  ┌───────┴────────┐  │
│  │ PipHidController│◄─┼─HID────►│  │  HID Mouse     │  │
│  │ (BluetoothHid- │  │ Reports │  │  Driver        │  │
│  │  Device)       │  │         │  │                │  │
│  └───────▲────────┘  │         │  └────────────────┘  │
│          │           │         │                      │
│  ┌───────┴────────┐  │         │                      │
│  │ AirMouseEngine │  │         │                      │
│  │ (Gyro filter)  │  │         │                      │
│  └────────────────┘  │         │                      │
└──────────────────────┘         └──────────────────────┘
```

**Ключевой трюк**: телефон регистрируется в системе как **HID Device** через `BluetoothHidDevice` API. Он объявляет себя в SDP-записи как «Mouse» с определённым HID Report Descriptor — набором байт, описывающих структуру отчётов (кнопки, X, Y, колесо). Операционная система принимающей стороны «видит» телефон как обычную BLE-мышь и подключает стандартный драйвер — **никакой софт на Mac не нужен**.

## 🐛 Известные проблемы

| Проблема | Решение |
|---|---|
| Mac не видит устройство | Убедитесь, что Bluetooth включён до запуска PipPad. Перезапустите приложение. |
| Курсор двигается рывками | Уменьшите чувствительность в приложении или увеличьте deadzone |
| Курсор не двигается после подключения | На Mac «Забыть устройство» и подключить заново |
| Приложение падает на Android 12+ | Разрешите `BLUETOOTH_CONNECT` и `BLUETOOTH_ADVERTISE` в настройках |
| Не работает Air Mouse | Проверьте, есть ли гироскоп: `adb shell dumpsys sensorservice \| grep Gyro` |
| Xiaomi / Realme / custom ROM не видят HID | Некоторые прошивки вырезают HID-профиль. Нужен другой телефон. |

Если проблема не описана — откройте [Issue](https://github.com/Vorozhka/PipPad/issues) с логом `adb logcat -s PipHid`.
